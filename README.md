# Binary Search Tree Visualization

该程序实现了一个二叉排序树的可视化工具，允许用户通过网页交互来插入、删除和查找节点，并动态地更新树的可视化表示。用户可以通过输入框输入数值，然后点击相应按钮来进行操作。

## 访问链接
[https://hoshigawarei.github.io/Binary_Search_Tree_Visualization/]


## 主要功能
- **节点插入功能:**

  用户可以输入一个整数值，然后点击插入按钮，将该值插入二叉搜索树中。插入完成后，树的可视化展示会自动更新。
- **节点删除功能**

  用户可以输入一个整数值，然后点击删除按钮，从二叉搜索树中删除该值。删除操作完成后，树的可视化展示会自动更新。
- **节点查找功能**

  用户可以输入一个整数值，然后点击查找按钮，检查该值是否存在于二叉搜索树中。若找到该节点，会弹出一个提示框显示节点存在；否则，提示框会显示节点不存在。
